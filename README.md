## Общие сведения

### Справочная информационная система

- Назначение: Справочная информация для посетителей медучереждения
- Хранение и отображение документов в формате PDF
- Аудитория: Посетители без IT-опыта, в т.ч. пожилые
- Язык интерфейса: Русский
- Режим работы: Офлайн — без интернета, локальная сеть / localhost
- Браузер: Chrome в kiosk mode, 1920×1080, горизонтально, сенсор
- адаптировано для php 8.4
- Framework: Laravel


Настроить .env

Выполнить:

composer intall

php artisan migrate

php artisan storage:link

npm run dev

php artisan server
